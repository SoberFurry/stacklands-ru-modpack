# Recipe Inspector — Stacklands Mod

Боковая панель рецептов для Stacklands. При наведении на рецепт в списке Ideas нажми **R** — рецепт откроется справа.

## Управление
| Действие | Что делает |
|---|---|
| **R** (наведись на рецепт в Ideas) | Добавить/убрать вкладку |
| **R** (наведись на вкладку в панели) | Закрыть вкладку |
| Клик по вкладке | Переключить активную вкладку |
| **×** на вкладке | Закрыть вкладку |
| **◀ ▶** | Переключать варианты рецепта (если их несколько) |
| Заголовок (тащи) | Переместить панель |
| **▼** | Свернуть/развернуть |
| **⚙** | Открыть настройки (игра ставится на паузу) |

## Настройки
- Показывать иконки карт
- Только открытые рецепты
- Размер шрифта: Малый / Нормальный / Крупный
- Макс. вариантов рецепта: 10 / 20 / 50
- Тёмная тема
- Прозрачность панели
- Дедупликация вариантов
- Показывать строку результата
- Показывать время крафта

## Установка
Скопируй содержимое папки (DLL + Icons + manifest.json) в:
```
C:\Users\<user>\AppData\LocalLow\sokpop\Stacklands\Mods\RecipeInspector\
```

## Сборка
```
dotnet build -c Release
```
Требуются DLL из: `H:\SteamLibrary\steamapps\common\Stacklands\Stacklands_Data\Managed\`  
*(или замени путь в RecipeInspector.csproj на свой)*

## Зависимости (runtime)
- **BetterSideBar** (опционально) — кнопка «Закрепить» появляется только если мод установлен
- **Russian Language** (опционально) — русские названия карт

## Структура файлов
```
RecipeInspector/
  Mod.cs              — точка входа, Harmony-патчи
  RecipeCache.cs      — кэш рецептов (строится 1 раз при загрузке)
  RecipePanel.cs      — UI панели, drag, collapse, вкладки, настройки
  RecipeSettings.cs   — настройки через PlayerPrefs (независимые от ПК)
  manifest.json
  RecipeInspector.csproj
  Icons/              — 40x40 PNG иконки (bold/solid стиль)
```
